# ผลตรวจ UI โดย AI (Gemini)

ตรวจเมื่อ 7/11/2569 12:10:47 · จอมือถือ 390×844 · เว็บ https://wattanasaw.github.io/i-you-alone/

**คะแนนความใช้งานง่าย: 6/10**

แอปพลิเคชันมีคอนเซปต์ดีและโครงสร้างหน้าชัดเจน แต่มีปัญหาด้าน Contrast ของข้อความ/ปุ่ม, ขนาดพื้นที่สัมผัส (Touch Target) เล็กกว่ามาตรฐานในหลายจุด และขาด Social Login ซึ่งสำคัญมากสำหรับกลุ่มเป้าหมายคนไทยวัยรุ่นและวัยทำงาน

## ควรแก้ก่อน
1. เพิ่ม Social Login (LINE / Google) ในหน้าเข้าสู่ระบบ (ภาพ 8) เพื่อเพิ่มอัตราการลงชื่อเข้าใช้ของคนไทย
2. ปรับ Contrast และสีพื้นหลังปุ่ม CTA 'ซื้อบัตร' ในหน้ารายละเอียดงาน (ภาพ 2) ให้ตัวหนังสือสีขาวอ่านชัดเจน
3. ขยายขนาดปุ่มตัวเลือกการเดินทาง (ภาพ 6) ให้ได้ขนาด Tap Target ขั้นต่ำ 44x44px
4. ปรับ Sticky Header ในหน้าลิสต์ (ภาพ 1) ให้ยุบขนาดลงเมื่อเลื่อนหน้า เพื่อไม่ให้บังพื้นที่เนื้อหา
5. ซ่อนฟิลด์ข้อมูลที่ว่างเปล่า เช่น 'ราคาเมนู: -' ในการ์ดสถานที่ (ภาพ 4) เพื่อความสะอาดตา

## ปัญหาที่พบ

|---|---|---|---|
| หน้าแรก (อีเว้นท์) — จอแรก | 🔴 สูง | ส่วนแสดงผลภาพการ์ด 'ห้ามพลาด' บดบังข้อความชื่องาน และป้ายวันที่ซ้อนทับภาพโปสเตอร์ ทำให้ข้อความบนภาพอ่านยาก | ปรับการวาง Date Badge ให้อยู่นอกภาพ หรือเพิ่ม Gradient Overlay สีดำโปร่งแสงด้านล่างภาพก่อนวางข้อความเพื่อเพิ่ม Contrast |
| รายละเอียดงาน | 🔴 สูง | ปุ่ม CTA หลัก 'ซื้อบัตร / ดูรายละเอียด...' ใช้ตัวหนังสือสีขาวบนพื้นหลังส้มไล่เฉดชมพู ทำให้ Contrast ต่ำอ่านยากมาก และปุ่มย่อย 4 ปุ่มจัดวางกระจัดกระจายกินพื้นที่ 2 แถว | เปลี่ยนสีพื้นหลังปุ่ม CTA หลักเป็นสีเข้มหรือปรับเฉดสีส้มให้เข้มขึ้นเพื่อผ่าน Contrast Ratio (อย่างน้อย 4.5:1) และรวมปุ่มย่อยเป็น 1 แถวแบบ Icon Button พร้อม Label ชัดเจน |
| รายละเอียดสถานที่ — แท็บการเดินทาง | 🔴 สูง | ปุ่มตัวเลือกประเภทการเดินทาง (ขับรถ, ขนส่งสาธารณะ, เดิน, จักรยาน) มีขนาดเล็กมาก (ความสูงต่ำกว่า 36px) และกดยาก | ขยายขนาดปุ่มให้มีความสูงอย่างน้อย 44px เพิ่ม Padding ด้านข้าง และใช้ Segmented Control ที่ชัดเจน |
| หน้าบัญชีสมาชิก | 🔴 สูง | หน้าเข้าสู่ระบบมีเพียงการส่ง OTP ผ่านอีเมล ขาดตัวเลือก Social Login (เช่น LINE, Google) ซึ่งคนไทยนิยมใช้มากที่สุด | เพิ่มปุ่ม 'เข้าสู่ระบบด้วย LINE' และ 'Google' ที่ส่วนบนของฟอร์ม เพื่อลดขั้นตอนการกรอกอีเมล |
| หน้าแรก — เลื่อนลงไปที่รายการงาน | 🟠 กลาง | เมื่อเลื่อนหน้าลง Header ค้นหาและชิปตัวกรอง (Filter Chips) ซ้อนทับกันหลายชั้น กินพื้นที่ความสูงหน้าจอไปเกือบ 25% | ปรับ Sticky Header ให้ยุบเหลือเพียงแถบค้นหากระทัดรัด (Compact Search Bar) เมื่อ Scrolled และซ่อนชิปหมวดหมู่เมื่อเลื่อนลง |
| หน้าที่เที่ยว — เลื่อนลงไปที่รายการ | 🟠 กลาง | รายการสถานที่แสดงค่า 'ราคาเมนู: -' เกือบทุกการ์ด ทำให้ดูเหมือนระบบโหลดข้อมูลไม่สมบูรณ์ | หากไม่มีข้อมูลราคา ให้ซ่อนแถว 'ราคาเมนู' ออกจากการ์ด หรือเปลี่ยนเป็นแสดงช่วงราคาโดยประมาณ เช่น '฿฿ (100-300 บาท)' |
| รายละเอียดสถานที่ — แท็บภาพรวม | 🟠 กลาง | สไตล์ของแท็บ 'ภาพรวม' และ 'การเดินทาง' ไม่สม่ำเสมอ สีของไอคอนและตัวหนังสือเมื่อเลือก/ไม่เลือกแท็บมีความสับสน | ใช้ Design System เดียวกันสำหรับ Tab Bar โดยให้แท็บที่ Active ใช้สีเข้ม/ไฮไลต์ชัดเจน และแท็บที่ Inactive ใช้สีเทากลางมาตรฐาน |
| รายละเอียดงาน | 🟢 ต่ำ | ปุ่มย้อนกลับ '<- กลับไปหน้ารวมงาน' ที่มุมซ้ายบนเป็นเพียงข้อความตัวเล็ก ความสูงต่ำกว่า 44px กดกดยากบนมือถือ | เปลี่ยนเป็น Icon Arrow Left พร้อมพื้นที่ Tap Target อย่างน้อย 44x44px |
| หน้าบันทึก | 🟢 ต่ำ | หน้าบันทึกเมื่อไม่มีข้อมูล (Empty State) วางองค์ประกอบอยู่ส่วนบนของจอ มีพื้นที่ว่างด้านล่างมากเกินไป และขาดปุ่มกระตุ้นการใช้งาน (CTA) | จัดวางไอคอนและข้อความให้อยู่กึ่งกลางหน้าจอ (Vertical Center) พร้อมเพิ่มปุ่ม 'ไปค้นหาอีเว้นท์' เพื่อดึงผู้ใช้กลับไปใช้งานหน้าหลัก |

## ทำได้ดีแล้ว
- แถบเมนูด้านล่าง (Bottom Navigation Bar) แบ่งหมวดหมู่ชัดเจนและคงที่ทุกหน้า
- การแบ่งแท็บ 'ภาพรวม' และ 'การเดินทาง' ในหน้าสถานที่ช่วยแยกประเภทข้อมูลได้ดี
- มีระบบกรองข้อมูลตามจังหวัดและช่วงเวลาที่ตอบโจทย์การค้นหาอีเว้นท์
