# ผลตรวจ UI โดย AI (Gemini)

ตรวจเมื่อ 16/11/2569 15:42:48 · จอมือถือ 390×844 · เว็บ https://wattanasaw.github.io/i-you-alone/

**คะแนนความใช้งานง่าย: 6/10**

ตัวแอพมีการจัดเลย์เอาต์ที่สะอาดและโทนสีดูทันสมัยเข้ากับกลุ่มวัยรุ่น/วัยทำงานได้ดี แต่ยังมีปัญหาเรื่องพื้นที่หน้าจอที่ถูกใช้ไปกับตัวกรองมากเกินไป คอนทราสต์ของข้อความสีเทายังอ่อนเกินไป และมีปัญหา Floating Bottom Bar บดบังเนื้อหาและปุ่มส่วนล่างสุดของหน้า

## ควรแก้ก่อน
1. เพิ่ม Padding-bottom ในทุกหน้าเพื่อป้องกัน Floating Bottom Nav บดบังเนื้อหาและปุ่มกดส่วนล่างสุด (หน้า 8)
2. ปรับลดขนาดพื้นที่ Search & Filter หน้าแรกให้อยู่ในแถวเดียวแบบเลื่อนแนวนอนเพื่อเพิ่มพื้นที่แสดงผลรายการ (หน้า 0)
3. เพิ่มความเข้มของสีตัวหนังสือสีเทา (Contrast Ratio) สำหรับรายละเอียดเวลาและสถานที่ให้ผ่านเกณฑ์ WCAG (หน้า 4)
4. ปรับขนาด Touch Target ของปุ่มรองในหน้ารายละเอียดงาน (บันทึก/ปฏิทิน/แชร์) ให้มีขนาดอย่างน้อย 44px (หน้า 2)
5. ปรับเลย์เอาต์ปุ่มเลือกการเดินทางในหน้าสถานที่ให้เป็น 2 คอลัมน์หรือ Scrollable Chips เพื่อลดความอัดแน่น (หน้า 6)

## ปัญหาที่พบ
| หน้าจอ | ระดับ | ปัญหา | วิธีแก้ |
|---|---|---|---|
| หน้าบัญชีสมาชิก | 🔴 สูง | แถบเมนูด้านล่าง (Bottom Navigation Bar) ลอยทับเนื้อหาและขั้นตอนการติดตั้งแอพส่วนล่างสุด ทำให้ผู้ใช้ไม่สามารถมองเห็นหรือกดได้สะดวก | เพิ่มระยะ margin-bottom หรือ padding-bottom ของคอนเทนเนอร์หลักในทุกหน้าอีกประมาณ 80-90px เพื่อไม่ให้ Floating Nav ทับเนื้อหา |
| หน้าแรก (อีเว้นท์) — จอแรก | 🟠 กลาง | ส่วนค้นหาและตัวกรองใช้พื้นที่ความสูงหน้าจอมากเกินไป (แถบค้นหา + แถบตัวกรอง 2 แถว + แบนเนอร์) ทำให้แสดงผลรายการอีเว้นท์ได้เพียงงานเดียวในจอแรก | รวมปุ่มตัวกรองให้อยู่ในแถวเดียวแบบเลื่อนแนวนอน (Horizontal Scroll) หรือเก็บตัวเลือก 'ใกล้ฉัน/ทุกจังหวัด' ไว้ในปุ่ม 'ตัวกรอง' เพื่อเพิ่มพื้นที่แสดงคอนเทนต์ |
| รายละเอียดงาน | 🟠 กลาง | กลุ่มปุ่มการทำงานรองใต้ปุ่มหลัก (บันทึก, Google Calendar, เพิ่มลงปฏิทิน, แชร์) จัดวางเป็น Grid ไม่เท่ากัน และขนาดปุ่มแตะยากบนจอขนาดเล็ก | จัดวางกลุ่มปุ่มรองเป็น 2 คอลัมน์ขนาดเท่ากัน (2x2 Grid) และเพิ่มความสูงปุ่มให้ได้มาตรฐานอย่างน้อย 44px |
| หน้าที่เที่ยว — เลื่อนลงไปที่รายการ | 🟠 กลาง | ข้อความรายละเอียด เช่น เวลาเปิด-ปิด และสถานที่ ใช้สีเทาอ่อนเกินไป คอนทราสต์ต่ำ ทำให้อ่านยากในสภาพแสงจ้า | ปรับสีข้อความรายละเอียดให้เข้มขึ้น (รหัสสีเข้มขึ้น เช่น #595959 หรือเทียบเท่า) ให้ผ่านเกณฑ์มาตรฐาน WCAG AA |
| รายละเอียดสถานที่ — แท็บการเดินทาง | 🟢 ต่ำ | ปุ่มเลือกรูปแบบการเดินทาง 4 ประเภทถูกบีบให้อยู่ใน 4 คอลัมน์ ทำให้ตัวอักษร 'ขนส่งสาธารณะ' ถูกบีบอัดจนดูแน่นและอ่านยาก | ปรับเปลี่ยนการจัดวางเป็นแถบแนวนอนที่เลื่อนได้ (Scrollable Chips) หรือจัดเป็น Grid 2x2 เพื่อให้ปุ่มมีขนาดใหญ่และอ่านง่ายขึ้น |

## ทำได้ดีแล้ว
- การเลือกใช้โทนสีและ Typography ดูทันสมัย ตรงกับกลุ่มเป้าหมายวัยรุ่นและคนทำงาน
- มีฟังก์ชันความสะดวกที่ตอบโจทย์ เช่น ปุ่มเพิ่มลง Google Calendar, .ics และปุ่มนำทาง
- หน้า Empty State (หน้าบันทึก) มีการแนะนำและปุ่มทางเลือก (CTA) ให้ผู้ใช้ใช้งานต่อได้ดี
