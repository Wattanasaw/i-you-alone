หลังบ้าน: เพิ่ม/แก้ไขงาน

วิธีใช้

  1. เลือกข่าวจากกล่องข่าว (ถ้ามี) หรือเลือกงานเดิมเพื่อแก้ไข หรือกรอกใหม่
  2. กด สร้าง JSON แล้วกด คัดลอก
  3. ไปที่ GitHub → ไฟล์ data/events.json → ✏️ Edit → วางเป็นรายการใหม่ในวงเล็บ [ ] (คั่นด้วยจุลภาค) → Commit
  4. หรือกด ดาวน์โหลด events.json ทั้งไฟล์ แล้วอัปโหลดทับไฟล์เดิม (ง่ายที่สุด)
