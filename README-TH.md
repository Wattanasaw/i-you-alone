# I You Alone — คู่มือติดตั้งและใช้งาน (ฟรี 100%)

โลโก้: `icons/icon.svg` (ไอคอนแอพ) และ `icons/logo-full.svg` (โลโก้พร้อมชื่อ ใช้ทำโพสต์/สื่อโฆษณาได้)

แอพรวมงานอีเว้นท์ในไทยแบบ **PWA** (เว็บแอพที่ติดตั้งลงมือถือได้เหมือนแอพจริง) ใช้บริการฟรีทั้งหมด

| ส่วน | ใช้อะไร | ค่าใช้จ่าย |
|---|---|---|
| โฮสต์แอพ | GitHub Pages | ฟรี |
| ดึงข่าวอัตโนมัติวันละ 2 รอบ | GitHub Actions + Google News RSS | ฟรี |
| AI สรุปข่าวเป็นร่างข้อมูลงาน (ไม่บังคับ) | Google Gemini API (โควต้าฟรี) | ฟรี |
| แผนที่/เส้นทาง | ลิงก์ Google Maps | ฟรี |
| ติดตั้งลงมือถือ | PWA "เพิ่มไปยังหน้าจอหลัก" | ฟรี |

## โครงสร้างไฟล์

```
index.html              หน้าแอพหลัก
admin.html              หน้าหลังบ้าน สร้าง/แก้ข้อมูลงาน (ไม่ต้องเขียนโค้ด)
js/config.js            ⭐ ตั้งค่าชื่อแอพ หมวดหมู่ โฆษณา ช่องทางติดต่อ
data/events.json        ⭐ ข้อมูลงานทั้งหมด
data/venues.json        สถานที่ + วิธีเดินทาง (BTS/MRT/รถเมล์/ที่จอดรถ)
data/ads.json           แบนเนอร์โฆษณาที่ขายตรงเอง
data/news.json          ข่าวที่ดึงอัตโนมัติ (ไม่ต้องแก้เอง)
scripts/update-news.mjs สคริปต์ดึงข่าว
.github/workflows/      ตั้งเวลาดึงข่าวอัตโนมัติ
```

## ขั้นตอนเปิดใช้งานจริง (ประมาณ 15 นาที)

1. สมัคร https://github.com (ฟรี)
2. กด **New repository** → ตั้งชื่อ เช่น `check-event` → เลือก **Public** → Create
3. กด **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `.github`) → Commit
   - ถ้าลากโฟลเดอร์ `.github` ไม่ขึ้น (ไฟล์ซ่อน) ให้สร้างไฟล์ใหม่ชื่อ `.github/workflows/update-news.yml` แล้ววางเนื้อหาจากไฟล์ในเครื่อง
4. ไปที่ **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
5. รอ 1–2 นาที แอพจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/check-event/`
6. ไปที่ **Actions** → เปิดใช้งาน workflow → เลือก "อัปเดตข่าวอีเว้นท์อัตโนมัติ" → **Run workflow** เพื่อทดสอบ

### (ไม่บังคับ) เปิด AI ช่วยสรุปข่าว
1. เข้า https://aistudio.google.com → Get API key (ฟรี)
2. ใน GitHub repo: **Settings → Secrets and variables → Actions → New repository secret**
   ชื่อ `GEMINI_API_KEY` ใส่คีย์ที่ได้
3. ครั้งถัดไปข่าวใหม่จะมีร่างข้อมูล (วันที่ ราคา สถานที่) ให้กดใช้ในหน้า `admin.html` (ข่าวที่มี 🤖)

> AI เป็นแค่ "ร่าง" เสมอ — ตรวจวันที่/ราคากับแหล่งข่าวก่อนกดเผยแพร่ เพื่อความน่าเชื่อถือของแอพ

## การอัปเดตงานประจำวัน

1. เปิด `https://ชื่อผู้ใช้.github.io/check-event/admin.html`
2. กดเลือกข่าวจาก "กล่องข่าว" → กรอก/แก้ข้อมูล วันที่ สถานที่ ราคา รายละเอียด ลิงก์ Affiliate
3. กด **ดาวน์โหลด events.json ทั้งไฟล์** (ข้อมูลตัวอย่างจะถูกลบออกให้อัตโนมัติ)
4. ใน GitHub ไปที่โฟลเดอร์ `data` → **Add file → Upload files** → อัปโหลด `events.json` ทับ → Commit
5. แอพอัปเดตภายใน 1–2 นาที

ถ้าสถานที่ยังไม่มีในรายการ ให้เพิ่มใน `data/venues.json` (ใส่ lat/lng จาก Google Maps: คลิกขวาที่จุด → คัดลอกพิกัด)
และ**ต้องใส่ `"province"`** เป็นรหัสจังหวัด เช่น `"bangkok"`, `"chiang-mai"`, `"phuket"` (ดูรหัสทั้ง 77 จังหวัดท้ายไฟล์ `js/i18n.js`)
ไม่งั้นงานจะไม่ขึ้นเมื่อผู้ใช้เลือกจังหวัด (สคริปต์ `check-data.mjs` จะเตือนให้)

## 3 ภาษา (ไทย / English / 中文)

- ข้อความหน้าจอทั้งหมดอยู่ใน `js/i18n.js` แก้คำได้ที่นั่น ชื่อหมวดหมู่ / สโลแกน / ข้อความแจ้ง Affiliate อยู่ใน `js/config.js`
- เนื้อหางานแต่ละงานแปลได้ 3 วิธี:
  1. **อัตโนมัติ (แนะนำ):** ใส่ `GEMINI_API_KEY` ใน GitHub Secrets แล้วระบบจะแปลงานใหม่ให้ทุกรอบที่ดึงข่าว (แปลเฉพาะช่องที่ยังไม่แปล ไม่ทับคำแปลที่คุณแก้เอง)
  2. **กรอกเองในหน้า admin:** กล่อง "🌐 คำแปล อังกฤษ / จีน"
  3. **ไม่แปล:** แอพจะแสดงภาษาไทยต้นฉบับ พร้อมบอกผู้อ่านว่าเป็นต้นฉบับภาษาไทย
- แปลในเครื่องเองก็ได้: `GEMINI_API_KEY=คีย์ของคุณ node scripts/translate.mjs`
- หัวข่าวในหน้าข่าวเป็นภาษาไทยจากสื่อไทย (แอพแจ้งผู้อ่านภาษาอื่นไว้แล้ว)

## รายได้

### 1. ลิงก์ Affiliate (เริ่มได้ทันที ฟรี)
- สมัคร Shopee Affiliate Program, Lazada Affiliate หรือเครือข่ายอย่าง Involve Asia / ACCESSTRADE
- ใส่ลิงก์ในช่อง "ลิงก์ Affiliate" ของงาน → แสดงเป็นกล่อง "🔥 ดีลเด็ด" พร้อมข้อความแจ้งว่าเป็นลิงก์พันธมิตร
  (การแจ้งนี้ควรเก็บไว้ ทั้งเพื่อความโปร่งใสและตามเงื่อนไขของโปรแกรม Affiliate)

### 2. ขายโฆษณาตรง (เริ่มได้ทันที ฟรี)
- แก้ `data/ads.json` ใส่รูปแบนเนอร์และลิงก์ของลูกค้า
- ตำแหน่ง: `home_top` (บนหน้าแรก), `list_inline` (แทรกระหว่างการ์ด), `detail` (หน้ารายละเอียด), `news` (หน้าข่าว)
- ขายแพ็กเกจ "ปักหมุดแนะนำ" ได้ด้วย: ติ๊ก `featured` ให้งานลูกค้าขึ้นบนสุด
- ใส่อีเมล/LINE ติดต่อใน `js/config.js`

### 3. Google AdSense (ทำทีหลังเมื่อมีผู้ใช้)
- ⚠️ AdSense มักไม่อนุมัติเว็บบนโดเมนฟรีอย่าง `github.io` — ต้องมีโดเมนของตัวเอง (ประมาณ 300–500 บาท/ปี)
  แนะนำเริ่มจาก Affiliate + โฆษณาตรงก่อน มีรายได้แล้วค่อยซื้อโดเมน
- ได้รับอนุมัติแล้ว ใส่ `adsenseClient` และ slot id ใน `js/config.js` — แอพจะเปลี่ยนเป็น AdSense ให้อัตโนมัติ

## ทดสอบในเครื่อง

```bash
node scripts/check-data.mjs
```

## ข้อควรรู้
- **ขึ้น Play Store / App Store ไม่ฟรี** (Google $25 ครั้งเดียว, Apple $99/ปี) — PWA ติดตั้งจากเว็บได้ฟรีและอัปเดตทันทีไม่ต้องรอรีวิว เมื่อพร้อมค่อยห่อขึ้น Play Store ด้วย PWABuilder.com ได้
- ข้อมูลการเดินทางใน `venues.json` เป็นข้อมูลเริ่มต้น ควรตรวจสอบเส้นทางรถไฟฟ้าล่าสุดอีกครั้ง โดยเฉพาะรอบเมืองทองธานี
- หน้าข่าวแสดงเฉพาะหัวข้อ + ลิงก์ไปต้นทาง (ไม่คัดลอกเนื้อข่าว) เพื่อไม่ละเมิดลิขสิทธิ์ ส่วนรายละเอียดงานควรเขียนสรุปด้วยภาษาตัวเอง
- `admin.html` เปิดได้ทุกคน แต่ใช้แค่สร้างไฟล์ ไม่สามารถแก้ข้อมูลบนเว็บได้ (ต้องอัปโหลดผ่าน GitHub ของคุณเท่านั้น)
