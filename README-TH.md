# I You Alone — คู่มือติดตั้งและใช้งาน (ฟรี 100%)

โลโก้: `icons/icon.svg` (ไอคอนแอพ) และ `icons/logo-full.svg` (โลโก้พร้อมชื่อ ใช้ทำโพสต์/สื่อโฆษณาได้)

แอพรวมงานอีเว้นท์ในไทยแบบ **PWA** (เว็บแอพที่ติดตั้งลงมือถือได้เหมือนแอพจริง) ใช้บริการฟรีทั้งหมด

| ส่วน | ใช้อะไร | ค่าใช้จ่าย |
|---|---|---|
| โฮสต์แอพ | GitHub Pages | ฟรี |
| ดึงข่าวอัตโนมัติวันละ 2 รอบ | GitHub Actions + Google News RSS | ฟรี |
| AI สรุปข่าวเป็นร่างข้อมูลงาน (ไม่บังคับ) | Google Gemini API (โควต้าฟรี) | ฟรี |
| แผนที่/เส้นทาง | ลิงก์ Google Maps | ฟรี |
| ติดตั้งลงมือถือ | PWA "เพิ่มไปยังหน้าจอหลัก" | ฟรี |

## โครงสร้างไฟล์

```
index.html              หน้าแอพหลัก
admin.html              หน้าหลังบ้าน สร้าง/แก้ข้อมูลงาน (ไม่ต้องเขียนโค้ด)
js/config.js            ⭐ ตั้งค่าชื่อแอพ หมวดหมู่ โฆษณา ช่องทางติดต่อ
data/events.json        ⭐ ข้อมูลงานทั้งหมด
data/venues.json        สถานที่ + วิธีเดินทาง (BTS/MRT/รถเมล์/ที่จอดรถ)
data/ads.json           แบนเนอร์โฆษณาที่ขายตรงเอง
data/news.json          ข่าวที่ดึงอัตโนมัติ (ไม่ต้องแก้เอง)
scripts/update-news.mjs สคริปต์ดึงข่าว
.github/workflows/      ตั้งเวลาดึงข่าวอัตโนมัติ
```

## ขั้นตอนเปิดใช้งานจริง (ประมาณ 15 นาที)

1. สมัคร https://github.com (ฟรี)
2. กด **New repository** → ตั้งชื่อ เช่น `check-event` → เลือก **Public** → Create
3. กด **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `.github`) → Commit
   - ถ้าลากโฟลเดอร์ `.github` ไม่ขึ้น (ไฟล์ซ่อน) ให้สร้างไฟล์ใหม่ชื่อ `.github/workflows/update-news.yml` แล้ววางเนื้อหาจากไฟล์ในเครื่อง
4. ไปที่ **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
5. รอ 1–2 นาที แอพจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/check-event/`
6. ไปที่ **Actions** → เปิดใช้งาน workflow → เลือก "อัปเดตข่าวอีเว้นท์อัตโนมัติ" → **Run workflow** เพื่อทดสอบ

### (ไม่บังคับ) เปิด AI ช่วยสรุปข่าว
1. เข้า https://aistudio.google.com → Get API key (ฟรี)
2. ใน GitHub repo: **Settings → Secrets and variables → Actions → New repository secret**
   ชื่อ `GEMINI_API_KEY` ใส่คีย์ที่ได้
3. ครั้งถัดไปข่าวใหม่จะมีร่างข้อมูล (วันที่ ราคา สถานที่) ให้กดใช้ในหน้า `admin.html` (ข่าวที่มี 🤖)

> AI เป็นแค่ "ร่าง" เสมอ — ตรวจวันที่/ราคากับแหล่งข่าวก่อนกดเผยแพร่ เพื่อความน่าเชื่อถือของแอพ

## 🤖 งานจริงอัตโนมัติ (ไม่ต้องทำอะไร)

วันละครั้ง เวลา 06:00 น. ระบบบน GitHub จะ:
1. **ดึงงาน** จากเว็บขายบัตร Eventpop และ Zipevent (ชื่องาน วันเวลา สถานที่ จังหวัด ราคา รูปปก ลิงก์ซื้อบัตร)
2. **กรองอัตโนมัติ** ตัดงานที่จบแล้ว งานไกลเกิน 1 ปี งานนอกประเทศไทย งานซ้ำ (งานเดียวกันจากหลายเว็บ) งานที่ไม่มีวันที่/สถานที่ และคำต้องห้าม (แก้ได้ที่ `BLOCK_WORDS` ใน `scripts/fetch-events.mjs`)
3. **จัดหมวดและจังหวัดเอง** และจับคู่กับสถานที่ใน `data/venues.json` (ได้ข้อมูลการเดินทางด้วย) สถานที่อื่นหาพิกัดจาก OpenStreetMap ให้
4. บันทึกที่ `data/auto-events.json` → แอพแสดงพร้อมรูปจริงและเครดิตแหล่งที่มา

**ควบคุมงานอัตโนมัติได้ที่หน้า admin:** เลือกงาน 🤖 → แก้ข้อมูล (จะทับข้อมูลอัตโนมัติ) หรือติ๊ก "🚫 ซ่อนงานนี้" → ดาวน์โหลด events.json → อัปโหลดทับ

**รายได้เพิ่ม:** ถ้าสมัครโปรแกรมพันธมิตรของเว็บขายบัตรได้ ใส่รหัสที่ `ticketAffiliate` ใน `js/config.js` ปุ่ม "ซื้อบัตร" ทุกงานจากเว็บนั้นจะใส่รหัสของคุณให้อัตโนมัติ

> รูปและข้อมูลเป็นของเว็บต้นทางและผู้จัดงาน แอพแสดงเครดิตและลิงก์กลับไปซื้อบัตรที่ต้นทางเสมอ หากเจ้าของขอให้นำออก ให้ติ๊กซ่อนงานนั้น

**Eventpop บล็อกเซิร์ฟเวอร์ของ GitHub** จึงตั้งให้คอมพิวเตอร์เครื่องนี้ดึงงานแทน วันละครั้ง 08:00 น. (`scripts/local-fetch.ps1`, ตั้งเวลาด้วย `scripts/install-local-fetch.ps1`, ดูผลที่ `%LOCALAPPDATA%\IYouAlone\fetch.log`)

### 🗺️ ที่เที่ยวยอดฮิต (หน้า "ที่เที่ยว")
`scripts/fetch-places.mjs` จะรวบรวมสถานที่วันละครั้ง:
- **สวนสัตว์ สวนสนุก/สวนน้ำ พิพิธภัณฑ์ อุทยาน คาเฟ่**
  - รายชื่อมาจาก Wikidata เรียงตามความดัง (จำนวนภาษาที่มีบทความ Wikipedia) หมวดละไม่เกิน 30 แห่ง
  - คำอธิบายมาจาก Wikipedia ทั้งไทย อังกฤษ และจีน
  - รูปมาจาก Wikimedia Commons พร้อมชื่อผู้ถ่ายและสัญญาอนุญาต
  - เวลาเปิด เว็บไซต์ เบอร์โทร และค่าเข้ามาจาก OpenStreetMap
- **คาเฟ่สัตว์**: มาจาก OpenStreetMap เฉพาะร้านที่ชื่อบอกชัดว่าเป็นคาเฟ่สัตว์ (คาเฟ่แมว คาเฟ่หมา คาปิบารา ฯลฯ)
- **บอร์ดเทรนด์**: ข่าวล่าสุด 30 วันของแต่ละหมวดจาก Google News ถ้าสถานที่ไหนอยู่ในข่าว จะขึ้นป้าย 🔥 กำลังมาแรง และขึ้นก่อน
- ถ้าแหล่งไหนล่ม ระบบจะใช้ข้อมูลชุดเดิมของหมวดนั้นไปก่อน
- สถานที่ที่ปิดไปแล้วแต่ Wikidata ยังไม่อัปเดต ให้ใส่ชื่อภาษาอังกฤษไว้ที่ `CLOSED` ในสคริปต์

### 🌙 ไนท์ไลฟ์ / ผับบาร์ / งานสปอนเซอร์
- ดึงจากหมวด nightlife และ party ของ Eventpop รวมถึงคอนเสิร์ตที่จัดในผับ บาร์ คลับ หรือรูฟท็อป
- ทุกงานในหมวดนี้ขึ้นป้าย **🔞 20+** และคำเตือนเรื่องแอลกอฮอล์ตามกฎหมายไทยโดยอัตโนมัติ
- งานที่มีแบรนด์สนับสนุน (เช่น "Singha Corporation presents …" หรือ "สนับสนุนโดย …") ขึ้นป้าย **🎁 สปอนเซอร์**

### 🧠 ให้ AI ตรวจงาน (ฟรี ต้องใส่คีย์ครั้งเดียว)
หลังดึงงาน `scripts/ai-review.mjs` จะส่งงานให้ Google Gemini ตรวจ:
- คัดงานปลอม งานทดสอบ งานภายในบริษัท การพนัน และเนื้อหาไม่เหมาะสมออก (ดูรายการที่ถูกตัดได้ที่ `aiRejected` ใน `data/auto-events.json`)
- แก้หมวดให้ถูก หาสปอนเซอร์ และระบุงาน 20+
- เขียนสรุปสั้นเป็นไทย/อังกฤษ/จีน งานที่ผ่านจะมีป้าย "🤖 AI ตรวจข้อมูลแล้ว"
- ผลจะจำไว้ใน `data/ai-cache.json` ไม่ถามซ้ำ (ใช้ไม่เกิน 10 คำขอต่อรอบ อยู่ในโควต้าฟรี)

**วิธีใส่คีย์:**
1. ไปที่ https://aistudio.google.com/apikey → **Create API key** (ฟรี ไม่ต้องผูกบัตร)
2. ไปที่ GitHub repo → **Settings → Secrets and variables → Actions → New repository secret**
3. Name: `GEMINI_API_KEY` · Secret: วางคีย์ → **Add secret**
4. ไปที่แท็บ **Actions → อัปเดตข่าวและงานอีเว้นท์อัตโนมัติ → Run workflow** เพื่อลองทันที

> ไม่ต้องใส่คีย์ในคอมพิวเตอร์ เครื่องนี้จะใช้ผลตรวจที่ GitHub จำไว้ จึงไม่เปลืองโควต้าซ้ำ

## 📱 แอพมือถือ (Android / iPhone)

แอพสร้างด้วย Capacitor จากโค้ดเว็บชุดเดียวกัน เมื่อแก้เว็บ แอพก็เปลี่ยนตาม
- แอพมีข้อมูลชุดหนึ่งติดเครื่องไว้ใช้ตอนออฟไลน์ และโหลดข้อมูลล่าสุดจากเว็บทุกครั้งที่เปิด
- ลิงก์ข่าวและลิงก์ขายบัตรเปิดในเบราว์เซอร์ในแอพ ส่วนปุ่มแผนที่เปิดแอพ Google Maps

**ทดลองใช้ Android (ฟรี):**
- GitHub สร้างไฟล์ APK ใหม่ทุกครั้งที่โค้ดแอพเปลี่ยน (แท็บ Actions → "สร้างแอพ Android")
- ไฟล์อยู่ที่หน้า Releases → `android-latest` หรือกดปุ่ม "📲 โหลดแอพ Android" ในหน้า "เกี่ยวกับ" บนมือถือ
- ลิงก์ตรง: https://github.com/Wattanasaw/i-you-alone/releases/download/android-latest/i-you-alone.apk
- เปิดไฟล์บนมือถือ แล้วอนุญาต "ติดตั้งแอพที่ไม่รู้จัก" ให้เบราว์เซอร์ เวอร์ชันใหม่ติดตั้งทับของเดิมได้เลย

> ไฟล์ทดลองเซ็นด้วยคีย์ทดลอง (`android/app/test-signing.p12`) ซึ่งเปิดเผยในโปรเจกต์ ใช้ทดลองเองเท่านั้น ห้ามนำไปขึ้น Play Store

**เมื่อพร้อมขึ้น Google Play ($25 จ่ายครั้งเดียว):**
1. สมัครที่ https://play.google.com/console (ยืนยันตัวตน) บัญชีส่วนตัวใหม่ต้องเปิดทดสอบแบบปิดกับผู้ทดสอบ 12 คน นาน 14 วัน ก่อนเปิดให้ทุกคน
2. สร้างคีย์ของคุณเองบนเครื่องที่มี Java:
   `keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000`
   **เก็บไฟล์และรหัสผ่านไว้ให้ดี** ห้ามอัปโหลดไฟล์นี้ขึ้น GitHub
3. ใส่ GitHub Secrets 4 ตัว:
   - `ANDROID_KEYSTORE_BASE64`: ได้จากคำสั่ง PowerShell `[Convert]::ToBase64String([IO.File]::ReadAllBytes("upload.jks"))`
   - `ANDROID_KEYSTORE_PASSWORD`
   - `ANDROID_KEY_ALIAS` (เช่น `upload`)
   - `ANDROID_KEY_PASSWORD`
4. รัน "สร้างแอพ Android" อีกครั้ง แล้วโหลด `play-store-aab` จากหน้าผลการรัน ไปอัปโหลดใน Play Console
5. ใส่ลิงก์นโยบายความเป็นส่วนตัว: https://wattanasaw.github.io/i-you-alone/privacy.html
6. ในแบบฟอร์มเนื้อหาแอพ ตอบว่ามีเนื้อหาเกี่ยวกับแอลกอฮอล์ (หมวดไนท์ไลฟ์)

**iPhone / App Store ($99 ต่อปี):**
- โปรเจกต์ iOS อยู่ในโฟลเดอร์ `ios/` แล้ว
- เช็กว่าสร้างได้ด้วย Actions → "ตรวจว่าแอพ iPhone สร้างได้" (ใช้เครื่อง Mac ของ GitHub ฟรี)
- การติดตั้งลง iPhone หรือส่งขึ้น App Store ต้องมีบัญชี Apple Developer และใช้ Xcode บน Mac (หรือบริการสร้างแอพบนคลาวด์)
- ระหว่างนี้ผู้ใช้ iPhone ติดตั้งจากเว็บได้: Safari → แชร์ → "เพิ่มไปยังหน้าจอโฮม"

**แก้แอพเอง:** แก้ไฟล์เว็บตามปกติ แล้วถ้าจะเปิดใน Android Studio ให้รัน `npm run app:sync` ก่อน
- เปลี่ยนไอคอน: แก้ `scripts/make-app-icons.mjs` แล้วรัน `node scripts/make-app-icons.mjs` ตามด้วย `npx capacitor-assets generate`
- โฆษณาในแอพ: AdSense ใช้ในแอพไม่ได้ แอพจึงแสดงเฉพาะโฆษณาตรงจาก `data/ads.json` ถ้าจะหารายได้จากโฆษณาในแอพต้องสมัคร AdMob ภายหลัง

## การอัปเดตงานประจำวัน

1. เปิด `https://ชื่อผู้ใช้.github.io/check-event/admin.html`
2. กดเลือกข่าวจาก "กล่องข่าว" → กรอก/แก้ข้อมูล วันที่ สถานที่ ราคา รายละเอียด ลิงก์ Affiliate
3. กด **ดาวน์โหลด events.json ทั้งไฟล์** (ข้อมูลตัวอย่างจะถูกลบออกให้อัตโนมัติ)
4. ใน GitHub ไปที่โฟลเดอร์ `data` → **Add file → Upload files** → อัปโหลด `events.json` ทับ → Commit
5. แอพอัปเดตภายใน 1–2 นาที

ถ้าสถานที่ยังไม่มีในรายการ ให้เพิ่มใน `data/venues.json` (ใส่ lat/lng จาก Google Maps: คลิกขวาที่จุด → คัดลอกพิกัด)
และ**ต้องใส่ `"province"`** เป็นรหัสจังหวัด เช่น `"bangkok"`, `"chiang-mai"`, `"phuket"` (ดูรหัสทั้ง 77 จังหวัดท้ายไฟล์ `js/i18n.js`)
ไม่งั้นงานจะไม่ขึ้นเมื่อผู้ใช้เลือกจังหวัด (สคริปต์ `check-data.mjs` จะเตือนให้)

## 3 ภาษา (ไทย / English / 中文)

- ข้อความหน้าจอทั้งหมดอยู่ใน `js/i18n.js` แก้คำได้ที่นั่น ชื่อหมวดหมู่ / สโลแกน / ข้อความแจ้ง Affiliate อยู่ใน `js/config.js`
- เนื้อหางานแต่ละงานแปลได้ 3 วิธี:
  1. **อัตโนมัติ (แนะนำ):** ใส่ `GEMINI_API_KEY` ใน GitHub Secrets แล้วระบบจะแปลงานใหม่ให้ทุกรอบที่ดึงข่าว (แปลเฉพาะช่องที่ยังไม่แปล ไม่ทับคำแปลที่คุณแก้เอง)
  2. **กรอกเองในหน้า admin:** กล่อง "🌐 คำแปล อังกฤษ / จีน"
  3. **ไม่แปล:** แอพจะแสดงภาษาไทยต้นฉบับ พร้อมบอกผู้อ่านว่าเป็นต้นฉบับภาษาไทย
- แปลในเครื่องเองก็ได้: `GEMINI_API_KEY=คีย์ของคุณ node scripts/translate.mjs`
- หัวข่าวในหน้าข่าวเป็นภาษาไทยจากสื่อไทย (แอพแจ้งผู้อ่านภาษาอื่นไว้แล้ว)

- สมัคร Shopee Affiliate Program, Lazada Affiliate หรือเครือข่ายอย่าง Involve Asia / ACCESSTRADE
- ใส่ลิงก์ในช่อง "ลิงก์ Affiliate" ของงาน → แสดงเป็นกล่อง "🔥 ดีลเด็ด" พร้อมข้อความแจ้งว่าเป็นลิงก์พันธมิตร
  (การแจ้งนี้ควรเก็บไว้ ทั้งเพื่อความโปร่งใสและตามเงื่อนไขของโปรแกรม Affiliate)

### 2. ขายโฆษณาตรง (เริ่มได้ทันที ฟรี)
- แก้ `data/ads.json` ใส่รูปแบนเนอร์และลิงก์ของลูกค้า
- ตำแหน่ง: `home_top` (บนหน้าแรก), `list_inline` (แทรกระหว่างการ์ด), `detail` (หน้ารายละเอียด), `news` (หน้าข่าว)
- ขายแพ็กเกจ "ปักหมุดแนะนำ" ได้ด้วย: ติ๊ก `featured` ให้งานลูกค้าขึ้นบนสุด
- ใส่อีเมล/LINE ติดต่อใน `js/config.js`

### 3. Google AdSense (ทำทีหลังเมื่อมีผู้ใช้)
- ⚠️ AdSense มักไม่อนุมัติเว็บบนโดเมนฟรีอย่าง `github.io` — ต้องมีโดเมนของตัวเอง (ประมาณ 300–500 บาท/ปี)
  แนะนำเริ่มจาก Affiliate + โฆษณาตรงก่อน มีรายได้แล้วค่อยซื้อโดเมน
- ได้รับอนุมัติแล้ว ใส่ `adsenseClient` และ slot id ใน `js/config.js` — แอพจะเปลี่ยนเป็น AdSense ให้อัตโนมัติ

## ข้อควรรู้
- **ขึ้น Play Store / App Store ไม่ฟรี** (Google $25 ครั้งเดียว, Apple $99/ปี) — PWA ติดตั้งจากเว็บได้ฟรีและอัปเดตทันทีไม่ต้องรอรีวิว เมื่อพร้อมค่อยห่อขึ้น Play Store ด้วย PWABuilder.com ได้
- ข้อมูลการเดินทางใน `venues.json` เป็นข้อมูลเริ่มต้น ควรตรวจสอบเส้นทางรถไฟฟ้าล่าสุดอีกครั้ง โดยเฉพาะรอบเมืองทองธานี
- หน้าข่าวแสดงเฉพาะหัวข้อ + ลิงก์ไปต้นทาง (ไม่คัดลอกเนื้อข่าว) เพื่อไม่ละเมิดลิขสิทธิ์ ส่วนรายละเอียดงานควรเขียนสรุปด้วยภาษาตัวเอง
- `admin.html` เปิดได้ทุกคน แต่ใช้แค่สร้างไฟล์ ไม่สามารถแก้ข้อมูลบนเว็บได้ (ต้องอัปโหลดผ่าน GitHub ของคุณเท่านั้น)
