# เติมข้อมูลสถานที่ด้วย Gemini (ทำเองแบบแมนนวล)

ใช้ prompt ถาม Gemini เพื่อเติมเวลาเปิด-ปิด ราคา สรุปรีวิว เคล็ดลับ และวิธีเดินทาง ให้สถานที่ที่ยังขาดข้อมูล
แอพจะแสดงข้อมูลชุดนี้พร้อมป้าย "🤖 สรุปโดย AI" และคำเตือนให้เช็กกับร้านก่อนไป
ข้อมูลจาก OpenStreetMap, รีวิวจาก Lemon8 และข้อมูลจากเจ้าของร้านจะใช้ก่อนเสมอ ข้อมูลจาก Gemini เติมเฉพาะช่องที่ยังว่าง

## ขั้นตอน
1. สร้างชุด prompt (สถานที่ที่ขาดข้อมูลมากที่สุดมาก่อน ชุดละ 25 ที่):
   ```bash
   node scripts/gemini-batches.mjs
   ```
   ได้ไฟล์ `gemini/prompts/batch-001.txt`, `batch-002.txt`, … (ใช้ `--kind nightlife` ถ้าต้องการเฉพาะผับ/บาร์)
2. เปิด Gemini แล้วเลือกโมเดลที่ค้นเว็บได้ (เช่น 2.5 Pro หรือ Deep Research) จากนั้นคัดลอกข้อความทั้งไฟล์ไปถาม
3. คัดลอกคำตอบทั้งหมด แล้วบันทึกเป็นไฟล์ใน `gemini/answers/` ตั้งชื่ออะไรก็ได้ เช่น `batch-001.txt`
   - ถ้าใช้หน้าเว็บ GitHub: เข้าโฟลเดอร์ `gemini/answers` → Add file → Create new file → วางคำตอบ → Commit
4. นำเข้า โดยเลือกวิธีใดวิธีหนึ่ง:
   - **วิธี ก:** รอรอบอัปเดตอัตโนมัติประจำวัน
   - **วิธี ข:** รันเองด้วยคำสั่งด้านล่าง
   ```bash
   node scripts/import-gemini.mjs
   ```
   ไฟล์ที่นำเข้าแล้วจะย้ายไปไว้ที่ `gemini/answers/done/`

## ระบบตรวจข้อมูลก่อนใช้
- `id` ต้องตรงกับสถานที่ในแอพ ถ้าไม่ตรงจะข้าม
- ข้ามข้อมูลที่ `confidence: "low"` หรือไม่มีลิงก์อ้างอิง (ไม่ใช้เนื้อหา และไม่ถามซ้ำ)
- `found: false` = Gemini หาสถานที่ไม่เจอ ระบบจะจำไว้และไม่ถามซ้ำ
- `closed: true` = หน้าสถานที่จะขึ้นคำเตือนว่าอาจปิดกิจการแล้ว
- เวลาเปิดต้องเป็นรูปแบบ OpenStreetMap ถ้าผิดรูปแบบจะไม่ใช้
- ราคาต้องอยู่ในช่วง 0–20,000 บาท

## ข้อควรระวัง
- ทำทีละชุด ไม่ต้องรีบ และอย่าใช้โปรแกรมอัตโนมัติถามแทน เพราะขัดเงื่อนไขของ Gemini และบัญชีอาจโดนระงับ
- ตอบซ้ำได้ ถ้าถามสถานที่เดิมอีกครั้ง ข้อมูลใหม่จะทับข้อมูลเก่า
- หลังนำเข้าแล้วให้รัน `gemini-batches.mjs` ใหม่ ระบบจะสร้างชุดใหม่จากเฉพาะสถานที่ที่ยังไม่ได้ทำ
